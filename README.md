**MargyT**

Мод TikTok для Android. Третий в серии после [Margy](https://github.com/narezany/Margelet).

---

Пакет `cat.narezany.tiktok`. Ставится **рядом** с официальным клиентом,
не поверх него. arm64 only.

- название и иконка — `MargyT`, мятный `#8DD1B0` из баннера Margy;
- подмена страны SIM: приложение видит NL-оператора вместо реального;
- экран **Настройки MargyT** со списком стран;
- рут не нужен — всё вшито в APK.

## Как это работает

Рута нет, значит нет и Xposed — хукать в рантайме нечем. Поэтому вызовы
переписываются прямо в байткоде: каждый

```smali
invoke-virtual {v0}, Landroid/telephony/TelephonyManager;->getSimCountryIso()Ljava/lang/String;
```

заменяется на

```smali
invoke-static {v0}, Lcat/narezany/tiktok/Region;->getSimCountryIso(Landroid/telephony/TelephonyManager;)Ljava/lang/String;
```

Формат инструкции (35c), число регистров и возвращаемый тип совпадают, поэтому
подстановка не требует пересчёта регистров. Ресивер уезжает первым аргументом и
игнорируется — он нужен только чтобы совпала арность.

Из 52 dex телефонию трогают пять; всего 26 call-site'ов. Ищет и правит их
[`inject/patch_callsites.py`](inject/patch_callsites.py) — по сигнатурам, а не по
смещениям, так что следующую версию TikTok он переживёт.

Сам `Region` и экран настроек компилируются из Java в отдельный `classes53.dex`
и докладываются в APK — ART подхватывает его как обычный multidex.

## Что меняется, а что нет

Подменяется то, что приложение читает с устройства: `TelephonyManager`
(страна SIM, оператор, MCC/MNC, состояние SIM), пропертя `gsm.*`, страна в
`Locale`. Язык интерфейса не трогается — меняется только регион.

Этого хватает на `carrier_region` и `sys_region`, то есть на выдачу и часть
фичегейтов. **`store_region` аккаунта прибит на сервере при регистрации** и
клиентом не меняется. IP — отдельная история, под него нужен VPN.

## Вход через Google

Работает. TikTok использует не Google Sign-In через GMS (который проверяет
пакет и SHA-1 подписи), а AppAuth с редиректом на кастомную схему
`com.googleusercontent.apps.<client_id>` и PKCE. Такие OAuth-клиенты Google по
подписи не проверяет, поэтому ресайн его не ломает — достаточно сохранить три
схемы в манифесте нетронутыми, что сборка и делает.

Нюанс: если рядом остался оригинальный TikTok, обе апки заявляют одну и ту же
схему, и на редиректе Android покажет выбор приложения. Схема задана client_id
тиктока, обойти нельзя — просто выбирай MargyT.

## Сборка

Нужен **universal** APK TikTok (на APKMirror тип **APK**, не **BUNDLE**),
`arm64-v8a`, `nodpi`. В репозиторий он не входит.

```bash
./build.sh path/to/tiktok.apk
```

Скрипт сам подтянет apktool, uber-apk-signer, d8 и android.jar, разберёт APK,
перепишет call-site'ы, подменит название с иконкой, переименует пакет,
соберёт и подпишет.

Подпись своя — иначе пакет рядом с оригиналом не встанет.

## Вариант для рута

В [`app/`](app) лежит LSPosed-модуль, делающий то же самое хуками, без
модификации APK. Оригинальный TikTok остаётся нетронутым, подпись цела,
обновления переживает. Нужен root.

## Структура

```
build.sh                 сборка из оригинального APK
inject/src/              Java, которая станет classes53.dex
inject/patch_callsites.py  переписывание вызовов TelephonyManager
icon_out/                иконка под все плотности
app/                     LSPosed-модуль (альтернатива для рута)
```
